2｜主控模块：整台 SST 的系统级大脑

主控不直接承担每只 SiC / IGBT 的高速开关动作，它负责系统级决策与协调。

主控硬件做什么

提供软件运行和实时计算平台，并连接整机：典型包括 CPU / MCU / DSP / FPGA、Ethernet / CAN / RS485 / 光纤、模拟/数字 I/O、时钟同步、隔离电源、存储与冗余。

主控软件做什么

决定整台设备怎么运行：运行状态机、Grid-following / Grid-forming、DC 母线控制、功率分配、模块均压/均流、故障处理、降额/恢复及对外协议。

电力电子控制深入到功率单元层级，拓扑、采样、保护、PWM / DAB 控制与器件行为高度耦合。因此“只买硬件、软件完全重写”并非天然可拆。

3｜Grid-following vs Grid-forming

最简单的判断标准：谁来建立电压和频率。

Grid-following

独立建立 V/f 的能力

对强电网的依赖

记忆法：GFL = “你给我电压和频率，我按你的节奏送功率”；GFM = “我来建立电压和频率，其他设备可以跟着我”。

5｜对 SE 合作的启示

华塑侧：倾向保留成套

  • 核心功率模块及功率单元
  • 模块级控制软硬件
  • 与自身拓扑强耦合的控制逻辑
  • 主控软硬件当前倾向沿用，后续按 SE 架构要求再决定替换/二次开发

SE侧：更适合掌握

  • 中压开关设备及认证体系
  • 整机系统集成、柜体与接口定义
  • MFT / 高频变压器：当前合作设想倾向 SE 提供并适配华塑 SST
  • 面向数据中心的最终外特性定义、系统级验证与产品责任
DD真正要锁：Spec ownership、Control ownership、System responsibility、IP / FTO、故障责任。

术语速查

点击展开。

SST
Solid-State Transformer，固态变压器。用电力电子实现电压变换、AC/DC、隔离与控制。
CHB
Cascaded H-Bridge，级联 H 桥。多个功率单元串联承担中压。
DAB
Dual Active Bridge，双有源桥。常用于隔离型双向 DC/DC。
MFT
Medium-Frequency Transformer，中频/高频变压器，承担隔离和变比。
Grid-following
跟网型：依赖外部电网给出电压、频率和相位基准，再按 P/Q 或电流目标工作。
Grid-forming
构网型：主动建立或支撑电压、频率，可在弱网/孤网中形成参考。
主控
系统级控制器：状态机、模式管理、功率分配、模块协调、保护策略、对外通信。
模块控制器
靠近功率单元，执行电压/电流环、PWM/DAB、采样和快速保护。
